# Panopto 개념 정리 도우미

Panopto 강의 페이지에서 자막/대본 텍스트를 모으고, 필요하면 OpenAI API로 개념 정리본을 만든 뒤 Notion 페이지로 업로드하는 크롬 확장 프로그램입니다.

현재 버전: `1.7.0`

## 주요 기능

- Panopto 대본/자막 자동 추출 시도
- 자동생성 자막 파일 후보 직접 조회
- 재생 중인 자막 누적 캡처
- 문장 정돈: 줄 정리, 중복 제거, 불필요한 UI/접근성 문구 제거
- GPT로 개념 정리 후 Notion 페이지 생성
- ChatGPT 프로젝트용 프롬프트 복사 및 프로젝트 열기
- 대본/정돈 결과 접기와 펼치기
- 영상 창을 닫거나 이동하면 해당 영상의 누적 자막 자동 초기화

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 `개발자 모드` 켜기
3. `압축해제된 확장 프로그램을 로드합니다` 클릭
4. 아래 폴더 선택

```text

```

## 화면 구성

확장 패널은 세 화면으로 나뉩니다.

- `텍스트`: 대본 추출, 문장 정돈, 재생 자막 캡처
- `전송`: GPT+Notion 업로드, ChatGPT 프로젝트 연결
- `설정`: OpenAI API 키, Notion 토큰, ChatGPT 프로젝트 URL 입력

## 기본 사용

1. Panopto 강의 페이지를 크롬에서 열고 로그인합니다.
2. 오른쪽 아래 `개념 정리` 버튼을 누릅니다.
3. `텍스트` 화면에서 `대본 추출`을 누릅니다.
4. 필요하면 `문장 정돈`을 누릅니다.
5. 본격적인 개념 정리와 Notion 업로드는 `전송` 화면에서 진행합니다.

## 자동생성 자막 캡처

Panopto 자동생성 자막은 전체 대본이 한 번에 노출되지 않고, 재생 중인 자막 한 줄만 보이는 경우가 있습니다.

이때는 아래처럼 사용합니다.

1. Panopto 자막을 켭니다.
2. 영상을 재생합니다.
3. `텍스트` 화면에서 `재생 자막 캡처 시작`을 누릅니다.
4. 버튼이 붉은색 `재생 자막 캡처 중`으로 바뀌면 캡처 중입니다.
5. 다시 누르면 일시중지됩니다.
6. 이어서 캡처하려면 같은 버튼을 다시 누릅니다.
7. 필요한 구간이 지나간 뒤 `누적 자막 불러오기`를 누릅니다.

누적 자막은 영상 ID별로 저장됩니다. 영상 창을 닫거나 다른 페이지로 이동하면 해당 영상의 누적 자막은 자동 초기화됩니다.

## 문장 정돈

`문장 정돈`은 개념 요약 기능이 아닙니다. GPT로 보내기 전에 대본을 가볍게 정리하는 전처리 기능입니다.

수행하는 일:

- 줄 정리
- 중복 줄 제거
- 자막 설정/다운로드 UI 문구 제거
- 접근성용 설명 제거
- 화면 오브젝트 설명 제거
- 플레이어 조작 문구 제거

문장 자체는 되도록 크게 바꾸지 않습니다.

제거 대상 예시:

```text
밝은 배경에 어두운 텍스트
어두운 배경에 밝은 텍스트
Download transcript
Auto-generated transcript. Edits may have been applied for clarity.
Auto-generated captions may contain errors.
Open captions settings menu
```

## GPT와 Notion 설정

Panopto 패널의 `설정` 화면에서 바로 입력할 수 있습니다.

- `OpenAI API Key`: OpenAI API 키
- `OpenAI Model`: 기본값 `gpt-5-mini`
- `Notion Integration Token`: Notion 통합 토큰
- `Notion 부모 페이지 URL 또는 ID`: 정리본을 넣을 Notion 페이지
- `ChatGPT 프로젝트 URL`: API 없이 ChatGPT 웹에서 정리할 때 사용할 프로젝트 링크

Notion 페이지에 업로드하려면, Notion에서 해당 Integration을 정리본을 넣을 페이지에 초대해야 합니다.

## 전송 기능

`전송` 화면에는 두 가지 방식이 있습니다.

- `GPT로 정리해서 Notion 업로드`
  - OpenAI API로 개념 정리
  - Notion API로 새 페이지 생성

- `ChatGPT 프로젝트에서 정리`
  - 대본과 정리 요청문을 클립보드에 복사
  - 저장된 ChatGPT 프로젝트 링크 열기
  - 사용자가 채팅창에 붙여넣어 진행

## 접기와 펼치기

대본 텍스트와 정돈 결과는 각각 접을 수 있습니다.

- `대본 텍스트` 바 클릭: 대본 영역 접기/펼치기
- `정돈 결과` 바 클릭: 결과 영역 접기/펼치기

긴 텍스트는 영역 내부에서 마우스 휠로 스크롤해서 봅니다.

## 주의

- 이 도구는 로그인된 브라우저 화면에서만 작동합니다.
- Panopto 영상에 자막/대본이 없으면 추출할 텍스트도 없습니다.
- API 키는 크롬 확장 프로그램 로컬 저장소에 저장됩니다.
- 공용 PC에서는 API 키를 저장하지 않는 편이 좋습니다.
- ChatGPT 프로젝트 기능은 ChatGPT 웹을 자동 조작하지 않습니다.
